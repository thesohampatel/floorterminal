# Project governance

FloorTerminal is maintained through public, reviewable changes under the
MIT License. Maintainers may triage issues, review contributions, manage releases,
and enforce the code of conduct. Material changes to workflow semantics, connector
security, persisted data, authentication, kiosk controls, or product scope require
documented compatibility, security, and operational review.

No contributor obtains authority over a deployment, facility, workforce, external
service, or safety process by contributing code. Deployers remain accountable for
site configuration, authorization, validation, training, operation, and compliance.

Maintainer succession and additional reviewer assignment should be recorded in a
public issue or pull request. Repository hosting controls—not invented placeholder
accounts in this file—must define actual branch owners and release permissions.
