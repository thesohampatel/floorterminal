# Support

FloorTerminal was developed and is maintained by **Soham Patel**. For help
with evaluation, setup, Raspberry Pi deployment, configuration, connector design, or
integration into an end-user system, email
[sohampatel1782@gmail.com](mailto:sohampatel1782@gmail.com) or open a GitHub issue in
this repository. GitHub is preferred for non-sensitive questions that may help other
users; email is appropriate when the initial request contains deployment context that
should not be public.

Use GitHub issues for reproducible, non-sensitive defects, documentation problems,
and feature proposals. Include the application version, operating system, CPU,
display resolution, relevant neutral configuration, expected behavior, actual
behavior, and offline reproduction steps.

Do not post credentials, connector secrets, production URLs, facility identifiers,
employee information, logs containing operational data, or vulnerability details.
Follow [SECURITY.md](SECURITY.md) for security reports. Community support is
best-effort; direct contact does not create a service-level agreement. The MIT License
provides the software without warranty or a guaranteed response or resolution time.
