# FloorTerminal brand mark

`floorterminal-mark.svg` is the source-of-truth master. Use it for new exports,
print, documentation, and any layout where vector artwork is supported.

The transparent PNG exports are supplied for application and launcher contexts:

- `floorterminal-mark-1024.png` — high-resolution application artwork
- `floorterminal-mark-512.png` — desktop/application packaging
- `floorterminal-mark-256.png` — documentation and interface artwork
- `floorterminal-mark-128.png` — launcher and interface artwork
- `floorterminal-mark-64.png` — compact launcher/interface artwork
- `floorterminal-mark-32.png` — smallest supported status/launcher use

## Meaning

The central touch represents the operator taking the first action. The four
stages around it communicate the FloorTerminal response lifecycle:

1. Coral — production fault or interruption
2. Amber — report and alert
3. Violet — coordinated response and work
4. Emerald — production restored and moving forward

## Usage

- Keep the original proportions and colours.
- Preserve clear space around the complete circular silhouette.
- Do not stretch, skew, rotate, recolour individual stages, or add effects.
- Prefer the SVG master at arbitrary sizes.
- Do not use the detailed mark below 32 px.
