# Operational sound assets

These WAV cues are original deterministic assets generated by
`scripts/generate_sound_assets.py`. They contain no samples, recordings, music,
speech, personal data, or downloaded third-party material. They are distributed
under this repository's MIT License and need no additional attribution.

Audio supplements visible status. It never replaces a safety alarm, machine
signal, work instruction, or accessibility accommodation. Validate volume against
the site's noise assessment before production deployment.
